How to run the A/B

The stylesheet + UMD bundle are chosen by query string:

  • ?build=cdn — Quasar 2.23.3 from jsDelivr (unpatched upstream; this is the default) → expected FAIL
  • ?build=dist — ./ui/dist/, i.e. drop this file in the repo root after pnpm build
  • ?build=unpatched / ?build=patched — ./dist-unpatched/ / ./dist-patched/ side-by-side local builds
  • ?base=<any/path/> — explicit directory holding quasar.prod.css + quasar.umd.prod.js

Vue is loaded from ./vue.global.prod.js if present, else from jsDelivr.
